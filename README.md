# House Price Prediction System

## Overview

A machine learning web application built with Django that predicts house prices using trained ML models.

## Features

- House price prediction
- Django web interface
- MongoDB database
- Docker support
- Docker Compose support
- REST API
- Responsive UI

## Tech Stack

- Python
- Django
- Scikit-learn
- MongoDB
- Docker
- Docker Compose
- HTML
- CSS
- JavaScript

## Installation

git clone <repo>

cd House-Price-Prediction

docker compose up --build

Open

http://localhost:8000
